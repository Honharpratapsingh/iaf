# Indian Art & Culture Map

*Explore India's rich artistic heritage through an interactive map.*

## About

The Indian Art & Culture Map is an interactive application designed to showcase the diverse traditional art forms across India. Users can explore the map and click on markers to discover detailed information about each art form, including its origin, historical context, techniques used, primary materials, notable artists, and cultural significance. 

## Features

- **Interactive Map Exploration**: Visually discover art forms plotted geographically across India.
- **Search Functionality**: Quickly find specific art forms by searching for their name, state, or region.
- **Category Filters**: Filter art forms by categories including Painting, Textile, Sculpture, Craft, Folk Art, Tribal Art, and Performance Art.
- **Responsive Design**: A seamless experience across desktop and mobile devices, featuring a mobile-friendly bottom-sheet panel for art details.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Honharpratapsingh/iaf.git
   cd iaf
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173/](http://localhost:5173/) in your browser.

## Build for Production

To create a production-ready build and preview it:

```bash
npm run build
npm run preview
```

## Data

The application features 21 carefully selected traditional Indian art forms. The data is backed by real researched content (no placeholder data) and covers diverse regions across North, West, Central, East, South, and Northeast India.
